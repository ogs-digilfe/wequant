# 新高値銘柄を探すcli

## 概要

`--start-date`と`--end-date`で指定した期間に、新高根の銘柄を出力するcli

# 作成開始条件

- 不明な点はユーザに確認すること

- 作成にあたり、不明な点や要件があいまいな点は、ユーザに確認してから作成してください。

## コマンド名

new-highs

### パラメータの種別

cliからの入力パラメータ、および入力パラメータが、内部処理で利用される際のオブジェクトタイプは、以下のとおりです。

| オプション | 既定値 | 意味 |
| --- | --- | --- |
| `--start-date` | 期間なし | `YYYY-MM-DD`形式<br>指定日以降の新高値のみ出力 |
| `--end-date` | 期間なし | `YYYY-MM-DD`形式<br>指定日以前の新高値のみ出力 |
| `--min-prev-high` | 期間なし | 整数<br>prev-high列の値が、指定した日数以上の新高値のみ抽出 |



## 出力

wequant.data_processing.PricelistPl.df(以下、PriclistPl.df)から抽出/加工したを一覧表を標準出力する。
なお、Pricelist.dfは、reviced_pricelist.parquetを読み込むこと。

### 出力列と計算

| 列 | 内容 |
| --- | --- |
| `date` | 日付 |
| `code` | 銘柄コード |
| `name` | 銘柄名 |
| `prev-high` | 何営業日(取引日)ぶりの新高値更新かの営業日数 |

### 抽出条件

新高値のうち、パラメータの条件でフィルタしたレコードを抽出

### ソート条件

- ソート対象列: [`date`, `prev-high`]
- `date`は昇順(古い順)、`prev-high`は降順に出力する
