# 売買シミュレーションをするコマンド

## 概要

reviced_pricelist.parquetのデータを利用し、--entryで指定した日付: 銘柄(または指定した日付翌営業日)の始値で購入し、決められた手じまい条件に合致したときに手じまったときの株価騰落シミュレーションをするコマンド  
すべてのサブコマンドで、--codeと--dateは、複数設定できるようにします。

## 作成開始条件

- 不明な点はユーザに確認すること
- 作成にとりかかる前に、作成する新規に作成するライブラリのメソッドまたはクラス、task、flowについて、ユーザとすり合わせをしてください。
- 作成にあたり、不明な点や要件があいまいな点は、ユーザに確認してから作成してください。

## コマンド名

手じまい条件は複数考えられ、条件ごとにオプションも異なるため、手じまい条件ごとにサブコマンドを作成します。

sim \<subcommand>


## サブコマンド

### thresholdサブコマンド

- --take-profitで指定した利確閾値を超えたら利確する
- --stop-lossで指定した損切閾値を超えたら損切りする

#### threshold入力パラメータ

| パラメータ | 既定値 | 意味 |
| --- | --- | --- |
| `--entry` | なし(必須指定) | <対象日>: <対象銘柄コード>の形式で指定する<br>複数設定できるようにする |
| `--take-profit` | なし(必須指定) | 利確閾値 |
| `--stop-loss` | なし(必須指定) | 損切り閾値 |
| `--entry-mode` | next-open | エントリタイミングの指定
| `--exit-mode` | next-open | 利益確定、または損切りの閾値を超えたときの手じまい方法の指定<br>(下表参照) |
| `--output-mode` | standard | コマンド実行結果出力方法の指定 |

入力パラメータの選択肢

- entry-mode

| 選択肢 | 意味 |
| --- | --- |
| `open` | --entryで指定した指定日以降で最初に価格データがある日 |
| `next-open` | --entryで指定した指定日より後で最初に価格データがある日 |

- exit-mode

| 選択肢 | 意味 |
| --- | --- |
| `intraday` | 逆指値等で、閾値で手じまいしたときの騰落を計算する
| `next-open` | 終値が閾値を超えた場合、翌営業日の始値で手じまいする

- output-mode

| 選択肢 | 意味 |
| --- | --- |
| `standard` | 標準出力する |
| `file` | ファイル出力する<br>パスは`data/output/sim/threshold-YYYYmmddHHMMSS.csv<br>ここで、日付はコマンド実行日時とする


#### threshold出力形式

以下のフォーマットで出力する

| 列 | 内容 |
| --- | --- |
| `code` | 銘柄コード |
| `name` | 銘柄名 |
| `entry_date` | 購入日 |
| `close_date` | 手仕舞日 |
| `updown` | 騰落率 |
| `benchmark` | 同期間の日経平均の騰落率 |
